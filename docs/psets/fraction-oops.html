Fraction Class — Problem Set

Learn OOP in Python step by step

Introduction

In this problem, you will implement a Fraction (rational number) class in Python. Fractions are numbers like 1/2, -3/4, or 7/1. They can be added, multiplied, compared, and reduced to their simplest form.

This project is designed to practice Object-Oriented Programming (OOP) in Python. The distribution code contains skeleton methods with clear TODOs. Your job is to fill them in, level by level.

NOTE: Carefully read the entire Problem Set before starting.
Also Carefully read the existing code and try to understand it.
You don’t have to add any new functions to the Fraction class.
Although feel free to test it out by using the class.

Goal

  • Implement the missing parts of the Fraction class.
  • Learn operator overloading in Python (+, *, ==, etc.).
  • Practice incremental problem solving level by level.
  • Use pytest to verify correctness.

Levels

Level 0: Implement get_gcd() using recursion.
Level 1: Representations and multiplication.
Level 2: Add, subtract, divide, abs, negation.
Level 3: In-place operations and normalization.
Level 4: Read-only properties.
Level 5: Comparisons.
Level 6: Right/Reverse operations with integers.
Level 7: Advanced features (hash, copy).
Level 8 (Extra ): Fraction + int / int + Fraction in all ways (not mandatory).

Before this, you implemented Fraction + Fraction, Fraction += Fraction, and int + Fraction.
Now you’ll implement: Fraction + int, Fraction += int for all four operations: +, -, ×, ÷.

Functions to Update:

  • __add__, __mul__, __sub__, __truediv__
  • __iadd__, __imul__, __isub__, __itruediv__

NOTE: Use isinstance() to check if other is a Fraction or int. You can reuse existing code by converting the int to a Fraction first.

Type Hinting

In the distribution code, type hints are used to show what kinds of values a function takes as input and what it returns. They don’t change how the program runs, but they make your code more readable and help tools like pytest or IDEs (like VS Code) catch mistakes earlier.

  • The general form is:
    def func_name(argument: type) -> return_type
  • Example from this problem set:
    def gcd(a: int | float, b: int | float) -> int | float

    This means:

    • a can be an int or a float.
    • b can also be an int or a float.
    • The function will return either an int or a float.

  • NOTE: Type hints are there to help you understand and avoid bugs — the Python interpreter will still run your code even if the hints are wrong. (But don’t ignore them! They’re part of the learning process.)
