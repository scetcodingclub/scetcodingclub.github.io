# NEXUS Coding Club Website

Visit the website at https://nexuscodingclub.github.io/

### How to Contribute

1. **Clone this repo:**

    `git clone https://github.com/nexuscodingclub/nexuscodingclub.github.io.git`

2. **Install the required node modeules using:**

    `npm install`

3. **Install live server extention on VS Code:**

    Go live on vs code and it will open the website on http://127.0.0.1:5501/. \
    Any changes made will reflect in real time.
